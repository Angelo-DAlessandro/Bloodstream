# Bloodstream — Share Edition v8 (Fun & Engagement)

This build focuses on making the game **more fun to actually play**, while keeping the scientific framing intact.

## New gameplay systems
- **Near-miss bonuses** for risky navigation
- **Flawless stage bonuses**
- **Fast-clear bonuses**
- stronger **combo multiplier**
- collectible temporary power-ups:
  - **Membrane Shield** — absorbs collisions
  - **O₂ Magnet** — pulls objectives toward the RBC
  - **Flow Frenzy** — faster movement and higher scoring
- faster risk/reward loop
- more rewarding stage clears
- more dramatic particles and sound feedback
- organ-specific mini-challenges retained
- spleen gauntlet / macrophage pressure retained
- iPhone-first analog joystick

## Goal
The game should be simple enough to understand immediately, but reward skill, speed, risk-taking, and clean runs.

## GitHub Pages
Upload:
- `index.html`
- `bloodstream_banner.png`

**Settings → Pages → Deploy from a branch → main → /(root)**
