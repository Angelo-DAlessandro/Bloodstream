# Bloodstream — Concept Art Game v2.1 iPhone

Optimized for iPhone landscape play.

## iPhone changes
- landscape-first game layout
- portrait rotate-phone prompt
- game canvas fills the screen
- larger left-thumb analog control
- large right-thumb Pulse button
- notch / Dynamic Island safe-area handling
- compact HUD
- no lower control bar while playing
- reduced accidental page scrolling / zooming

## Recommended
Open the GitHub Pages link in Safari and rotate the iPhone to landscape.

## Controls
Desktop:
- Arrow Keys / WASD
- Space = Pulse

iPhone:
- left thumb = movement
- right thumb = Pulse
