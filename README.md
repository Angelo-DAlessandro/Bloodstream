# Bloodstream — Concept Art Game v2

This build extends the spleen mission into a real five-level arcade campaign.

## Spleen campaign
1. **Red Pulp** — collect 6 blue energy nodes.
2. **Sinus Maze** — survive 12 seconds.
3. **Macrophage Surge** — destroy 8 white cells using Pulse.
4. **Power Run** — collect 4 power-ups.
5. **Exit Corridor** — survive 14 seconds, then reach the gold exit.

After escaping the spleen, the **Final Delivery** mission begins.

## Controls
- Desktop: Arrow Keys / WASD to move; Space to Pulse.
- Mobile: touch pad + Pulse button.

## Power-ups
- ATP — speed boost
- Carnitine — restores HP
- Vitamin C — restores HP
- Glutathione — restores more HP
